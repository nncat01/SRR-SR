# SRR-SR

Automatic generation of RULE-SET .list files for the Shadowrocket proxy/VPN client

The source files used are Sing-box .srs files from the  [frayZV/simple-ru-routing](https://github.com/frayZV/simple-ru-routing) repository￼

Built based on the parser from  [Master-Yoba/shadowrocket-rules](https://github.com/Master-Yoba/shadowrocket-rules)￼.

In theory, it should also be compatible with Surge
